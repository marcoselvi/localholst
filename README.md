# localholst

A minimal listening page for Gustav Holst's *The Planets*, Op. 32, on repeat.
Playback follows a shared UTC timeline, with a read-only progress bar, planetary
colours, and a favicon that follows the current movement. Synchronisation depends
on accurate device clocks; browsers may require a tap before audio can start.

## Recording

NYO Canada, conducted by Michael Francis, at Jack Singer Hall, Calgary, on
August 9, 2015. The unchanged recording streams from IMSLP, which lists it under
[CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
